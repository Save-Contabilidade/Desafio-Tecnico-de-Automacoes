# Critérios de Avaliação

A avaliação considera o conjunto da entrega, e não apenas o resultado final.

## Funcionalidade

Será observado se a solução:

- processa corretamente o arquivo de entrada;
- valida os dados;
- consome a API corretamente;
- trata erros temporários e permanentes;
- gera o arquivo de saída;
- gera logs;
- apresenta resumo da execução.

## Qualidade técnica

Serão observados:

- clareza do código;
- organização do projeto;
- responsabilidades bem separadas;
- nomes de funções, classes e variáveis;
- facilidade de manutenção;
- tratamento de exceções;
- segurança de configurações e credenciais;
- testes automatizados, quando existentes.

## Git e entrega

Também serão considerados:

- uso correto de branch;
- qualidade e frequência dos commits;
- mensagens de commit;
- Pull Request;
- documentação;
- facilidade para executar o projeto em uma máquina limpa.

## Avaliação técnica posterior

Após a entrega, poderão ser solicitadas explicações ou pequenas modificações no código submetido.
